###

<p data-importer="text" align="center">I wrote my first line of code in 2024. Before that I spent 18 years on roofs, the last few running my own business as a master roofer. <br><br>That background still shows in how I work. A roof doesn't get a second chance. If it leaks, someone's living room is ruined. So you check twice, you don't cut corners, and you finish what you started. I write code the same way. Better done properly once than badly twice.<br><br>You sit down with nothing but your thoughts and a few lines of text, and you can build something that changes how people work. No material, no scaffolding, no crane. I also like the point where software meets hardware, where a few lines of code make something physical happen.<br><br>Right now I'm building out my homelab. Virtualization, containers, making my house actually smart, running AI models locally, and learning how to secure all of it properly. Turns out infrastructure scratches the same itch as a well built roof. You only notice it when it fails, so it had better not.<br><br>🌐 [Check out my portfolio](https://alexander-ruppel.de)</p>
